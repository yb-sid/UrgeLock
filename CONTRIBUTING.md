# Contributing

## Dev setup
- macOS 13+
- Xcode Command Line Tools: `xcode-select --install`
- `make app` builds `build/UrgeLock.app`
- `make run` opens it

## Commits
Keep commits focused. Do not commit secrets or notarization certs.
